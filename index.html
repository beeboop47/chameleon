Find the Impostor

Jester: wants to be voted out. Assassin: has a target to get voted out. Seer: learns about either a player (who is a special role or an impostor) or a special role. Double Agent: appears as impostor to impostors but is actually innocent. Note: By default, Assassin behaves like an impostor for what they see (they do not see the shared phrase). Other special roles still see the phrase by default unless configured manually.
In Bluff mode, roles who do NOT see the shared phrase (normally impostors and assassins) will be shown this customizable hint instead of the phrase.
In Question mode players answer a prompt privately. Players should not know whether they're innocent or an impostor (except special roles like Assassin/Seer/Jester who are told their role). When everyone has submitted, the non-impostor question and everyone's answers are revealed.
Manual mode per-player customization is supported. Players will not be informed if a player-specific word is used — only the host summary reveals custom words.
Note: The API key is used directly from your browser to call OpenAI. It is not stored by the app. If you are hosting this for others, prefer a server-side integration for safety.
When Lights out is enabled, impostors (and assassins treated as impostors) will not see other impostors in their 'impostors seen' list.
